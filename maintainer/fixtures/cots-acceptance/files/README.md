# csvsum acceptance tests

Acceptance tests for **csvsum 4.2**, a command-line tool supplied by Example Vendor Ltd., before the finance team adopts it.

We do not own csvsum. The release in `vendor/csvsum/` is kept exactly as delivered. Behavior that contradicts the vendor's manual or our requirements is reported to the vendor; the owner decides whether to wait for a fix or accept the deviation.

## Run

    python3 -m unittest

Agent instructions are in AGENTS.md.
